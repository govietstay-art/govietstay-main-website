GOVIETSTAY LOCAL POINT - GOI CAI DAT WEBSITE
============================================

Duong dan sau khi cai:
https://GoVietStay.com/ru/local-point

CACH CAI NHANH
1. Giai nen file ZIP nay.
2. Copy toan bo thu muc da giai nen vao thu muc goc:
   Documents\GitHub\govietstay-main-website
3. Chay file: CAI-DAT-LOCAL-POINT.bat
4. Tai thu muc govietstay-main-website, chay:
   npm run dev
5. Mo tren may tinh:
   http://localhost:3000/ru/local-point
6. Kiem tra xong thi dua code len website nhu quy trinh binh thuong cua anh.
