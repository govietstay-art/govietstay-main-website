GoVietStay Agarwood Da Nang – DEPLOY V1
==========================================

Mục tiêu:
- English: https://www.govietstay.com/travel/agarwood-da-nang
- Chinese: https://www.govietstay.com/cn/agarwood-da-nang

Logo:
- Trang dùng trực tiếp logo official đang có trên website:
  public/govietstay-logo.jpg

Cách chạy:
1. Giải nén ZIP.
2. Copy 2 file:
   - DEPLOY-AGARWOOD-DANANG-EN-CN-V1.bat
   - AGARWOOD-DANANG-PAYLOAD.zip
   vào thư mục gốc govietstay-main-website (nơi có package.json).
3. Double-click DEPLOY-AGARWOOD-DANANG-EN-CN-V1.bat.
4. File .bat sẽ:
   - backup file cũ nếu có,
   - cài 2 landing page,
   - copy bảng giá,
   - npm run build toàn bộ website,
   - chỉ stage các file Agarwood,
   - commit,
   - git push origin main,
   - Vercel tự deploy.

An toàn:
- Nếu build lỗi: KHÔNG commit / KHÔNG push.
- Nếu có file đã stage từ trước: KHÔNG tự commit để tránh trộn thay đổi khác.
