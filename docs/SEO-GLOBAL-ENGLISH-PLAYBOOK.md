# GoVietStay Global English SEO Playbook

- Root `/` remains the canonical English commercial homepage.
- Do not create a duplicate `/en`.
- `/travel` is the English informational authority hub.
- `/travel/[slug]` contains 17 distinct search-intent pages.
- Commercial pages remain under `/tours/...` and `/visa`.
- Use generic English hreflang `en`.
- Guides use Article + BreadcrumbList + FAQPage.
- `/travel` uses CollectionPage + ItemList.
- Never use fake review/rating schema.
- Visa claims must point travellers back to official Vietnam Immigration sources.
- Weather, crowd levels, visibility and marine operation are never guaranteed.
- Build must pass before Git push.
- Local `/admin` work is never staged with SEO.
